# 执行路线：从现在到能玩

> 单人项目。每个阶段都有明确的"完成标准"，达不到就别进下一阶段。

---

## 阶段 0　拍板与验证　【0.5–1 天】

1. **读 `docs/05-compliance.md`**，决定你接受哪一档风险（D-4）
2. **跑通本仓库**：
   ```bash
   npm test && npm run dict && npm run board && npm run demo
   ```
   然后用浏览器打开 `dist/board.html`，看看棋盘长什么样、配色顺不顺眼
3. **进游戏，按 `docs/03-verify-in-editor.md` 逐条验证**，把答案填回 `docs/00-decisions.md`
4. 拍板 D-1（语言方案）、D-2（UI 路线）、D-3（编辑模式）

**完成标准**：`docs/00-decisions.md` 的四个待定项全部有了答案。

---

## 阶段 1　词典　【1–2 天】

这是最该用工具链解决、也是最容易低估的部分。

1. 准备词表放进 `data/words/`（注意授权；样例表只有 57 词，仅够跑通流程）
2. 跑 `npm run dict -- --in data/words/你的表.txt --buckets 16`
3. 看输出的分桶均匀度。**如果最大桶的词数 × 每词所需节点数 > 3000，就加桶数**
4. 估算每词在节点图里占几个节点 → 反推桶数。这个数只能实测，先在编辑器里手工搭一个
   10 词的桶，数一下节点数

**关键约束提醒**：
- 单张节点图 ~3000 节点上限
- genshin-ts 的 `dict(...)` 是**只读**的 —— 词典正好适配
- **可变状态（棋盘/手牌/分数）必须用节点图变量**，不能用 `dict()`

**完成标准**：能在编辑器里查一个词并返回 true/false，且节点数在安全线内。

---

## 阶段 2　UI 骨架　【2–4 天，取决于 P0-1 的答案】

按 D-2 的决定走对应路线：

- **2D UI 控件网格**：先做一行 15 格，量清楚工时，再决定是手摆还是找批量办法
- **Ayaya HTML→.gil**：拿 `dist/board.html` 试，改 `tools/gen-board-html.mjs` 的输出去适配它的格式要求
- **3D 实体棋盘**：退路方案，用编辑工具的网格阵列批量生成

同时把这三个现成控件接上，能省大量自造轮子的时间：
- **计分板** → 2–4 人分数栏
- **消息队列** → "XX 拼出 XXX，得 N 分" 战报流
- **卡牌选择器** → 确认落子 / 质疑对手

**完成标准**：棋盘和手牌栏在游戏里显示正确，点击格子有反馈（哪怕只是变个色）。

---

## 阶段 3　核心逻辑上机　【3–5 天】

把 `src/core/` 的逻辑搬进节点图。**照着 `src/adapters/README.md` 的改写清单逐条处理**
（浮点/整数、只读字典、无递归、无 `Object.*` 等）。

搬运顺序（每步都能单独验证，别一次搬完）：
1. 棋盘数据结构 + 渲染一个写死的棋局
2. 发牌 / 补牌
3. 落子几何校验（`validateGeometry`）
4. 取词（`extractWords`）← **最难，重点测**
5. 词典校验（接阶段 1 的桶）
6. 计分（`scoreTurn`）
7. 回合推进与结束判定

**每搬完一步，就用 `src/core` 的对应测试当作"标准答案"去对照局内表现。**
这是本仓库最大的价值：你有一套可信的参考实现。

**完成标准**：单机试玩能完整走完一局。

---

## 阶段 4　多人与 AI 假人　【2–3 天】

1. 用官方「多人试玩」（支持模拟延迟）拉 2 人、再拉满 4 人
2. 重点测：回合锁定是否生效、词典校验延迟、多人同时点同一格的冲突
3. **AI 假人**：`tools/demo-game.mjs` 里的 `pickMove()` 就是雏形。
   6.7 上线的「复杂造物编辑模块」支持节点图自定义 AI 状态，可以把 2–3 个位置做成假人，
   一个人也能跑通 2–4 人的全部逻辑分支

**完成标准**：4 人局能完整走完，无状态不同步。

## 每个阶段都适用的纪律

1. **严禁高频轮询**。社区实测 tick 模拟会在高峰期让地图报错。一切事件驱动。
2. **服务端权威**。词典校验和计分绝不放客户端。
3. **小步验证**。每加一个功能就试玩一次，别攒着。
4. **`src/core` 是真理来源**。局内表现和本地测试对不上时，先信测试，去查节点图哪里搬错了。
